# 📊 Dashboards - AprovaEdu Analytics

Este projeto inclui **duas versões** do dashboard interativo para demonstração de diferentes capacidades.

## 📁 Arquivos Disponíveis

### 1. `dashboard.html` (Versão Cliente)
**Propósito:** Representar o branding do cliente fictício AprovaEdu

**Paleta de cores:**
- Azul Navy: `#1B3A5C` (corporativo, educacional)
- Azul Médio: `#2A5C8A` (gráficos principais)
- Laranja: `#E07A3F` (destaques/acentos)

**Uso:** Esta é a versão que seria entregue ao cliente (cursinho pré-vestibular) em um cenário real.

---

### 2. `dashboard_logap.html` (Versão Logap)
**Propósito:** Demonstrar adaptação à identidade visual da Logap

**Paleta de cores:**
- Azul Navy Tech: `#0A1628` (alinhado ao site Logap)
- Azul Cyan: `#00A8E8` (cor principal tech/inovação)
- Azul Claro: `#00D4FF` (acentos modernos)

**Diferenciais:**
- Gradiente tech no header (3 tons de azul)
- Box-shadow com tom cyan para efeito tech
- Tags de badge em azul claro
- Footer indicando versão adaptada

**Uso:** Criada especificamente para demonstrar:
1. Atenção ao branding corporativo da empresa avaliadora
2. Capacidade de adaptação visual rápida
3. Fit cultural e alinhamento de identidade visual

---

## 🎯 Por que duas versões?

Em projetos de consultoria/analytics reais, dashboards são frequentemente adaptados:
- **Versão cliente:** Reflete o branding da empresa que receberá o entregável
- **Versão interna:** Pode seguir identidade visual da consultoria

Esta dualidade demonstra:
- ✅ Flexibilidade de design
- ✅ Atenção aos detalhes
- ✅ Pensamento estratégico sobre branding
- ✅ Profissionalismo em deliverables

---

## 🚀 Como visualizar

Ambos os arquivos são **standalone** (HTML com dados embutidos):

**Opção 1: Localmente (sem servidor)**
1. Navegue até a pasta `outputs/`
2. Dê duplo clique em qualquer um dos arquivos
3. O dashboard abrirá no seu navegador padrão
4. **Não requer servidor** ou conexão com internet

**Opção 2: Via GitHub Pages (se disponível)**
- Dashboard padrão: `https://SEU_USUARIO.github.io/aprovaedu-analytics/outputs/dashboard.html`
- Dashboard Logap: `https://SEU_USUARIO.github.io/aprovaedu-analytics/outputs/dashboard_logap.html`

**Opção 3: Screenshots estáticos**
- Veja pasta `screenshots/` para visualizações em PNG (se disponíveis)

---

## 📝 Nota Técnica

Ambas as versões:
- Utilizam Plotly.js para gráficos interativos
- Possuem os mesmos dados e análises
- São totalmente responsivas (mobile/desktop)
- Diferenciam-se APENAS na paleta de cores e branding

O código-fonte é idêntico exceto pelas variáveis CSS e JavaScript de cores.
